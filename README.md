## 🚀 Featured Project: Salesforce Developer Lab (v2.0)

A hands-on, enterprise-grade Salesforce project built with production-ready Apex architecture and an interactive web studio.

* 🌐 **Live Interactive Platform:** [salesforce-developer-lab.vercel.app](https://salesforce-developer-lab.vercel.app)
* 🎮 **Interactive Studio IDE:** [salesforce-developer-lab.vercel.app/studio](https://salesforce-developer-lab.vercel.app/studio)
* 📦 **Repository:** [umendrabhati2001-ux/salesforce-developer-lab](https://github.com/umendrabhati2001-ux/salesforce-developer-lab)

### Key Highlights:
* **Bulkified Architecture:** Strict Separation of Concerns pattern (`CaseTrigger` → `CaseTriggerHandler` → `ComplaintService`).
* **Governor Limit Safe:** 0 SOQL inside loops, 0 DML inside loops.
* **100% Test Coverage:** Comprehensive test suite with `TestDataFactory` for deterministic unit testing.
* **Companion Web App:** Next.js 15 studio to explore code structure, Apex classes, and live documentation.
